# Celerity — Twitter demo video (roadmap + script)

**Goal:** You talking + screen demo + simple pop-up text. Not a motion graphic.  
**Tone:** Public / Twitter — plain words.  
**Length:** ~60–75 seconds (30s teaser included).  
**Aspect:** 9:16 or 1:1. Always burn-in captions.  
**Live URL:** https://stellar-celerity.me/

---

## Story (keep it this simple)

```
1. What it is     → “This is Celerity…”
2. The problem    → millions of people waiting
3. The solution   → one clear promise
4. Easy flow      → lock → storm → wallet → cash out
5. Close          → try it
```

---

## How to use this file

Shoot **one chapter at a time**. Edit in order.

| Label | Meaning |
|-------|---------|
| **TALK** | You on camera (or voiceover) |
| **SCREEN** | Phone / laptop recording |
| **POP** | Simple text overlay |
| **CUT** | Hard cut — end of chapter |

This is Celerity — relief disbursement for farmers.

## Words to avoid

| Don’t say | Say instead |
|-----------|-------------|
| Smart contract / Soroban | “the app” / “the system” |
| Oracle | “storm confirmation” |
| Escrow | “money set aside” |
| Idempotent | “can’t pay twice by accident” |
| SEP-24 / SEP-31 | “cash out” (+ say demo) |
